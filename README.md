# Ask Jomo Kenya — static website

Responsive GitHub Pages-ready website with the Training / Agency / Consultancy funnel, service categories, industry-specific WhatsApp links, a short lead qualification form, six SEO-focused blog guides, metadata, Open Graph cards, JSON-LD structured data, robots.txt, sitemap.xml, custom 404 and privacy note.

## Before publishing
1. The canonical URLs, structured data and sitemap currently use `https://askjomo.com/`. Replace these if the production domain is different.
2. Confirm all social profile URLs, especially the supplied Instagram handle `ask_jomo_kenka`.
3. The CV was not included with the uploaded images, so the owner biography avoids unverified employers, dates, credentials and results. Provide the CV to add a factual profile.
4. Confirm business hours and the active email inbox. `hello@askjomo.com` was not added to visible content; ensure any email used later is active.
5. Prices were not hard-coded because the supplied poster has campaign figures that may not represent the full service price list. Add approved prices after confirming current offers.
6. Test every CTA and WhatsApp message on mobile before launch.

## GitHub Pages deployment
1. Create a GitHub repository and upload the contents of this folder to the repository root (not the ZIP itself).
2. Open repository Settings → Pages. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
3. Configure a custom domain and matching DNS records if using your own domain. Update canonical URLs and sitemap to match it.
4. Test the published pages and submit `/sitemap.xml` in Google Search Console and Bing Webmaster Tools.
